# دليل اختبار الـAPK على Android

هذا الدليل لتثبيت نسخة debug من **مدير الديون** على هاتف حقيقي أو محاكي، واختبار
الشاشات السبع، والمحاذاة من اليمين لليسار (RTL)، وإدخال النص العربي.

المهمتان المرتبطتان: `MAG-7` (التثبيت وتدفق الشاشات) و`MAG-8` (RTL والخط والإدخال العربي).

   ← قسم **Artifacts** ← نزّل `debtmanagerpro-debug-apk.zip` ← فك الضغط.
   (تنزيل الـArtifacts يتطلب تسجيل الدخول إلى GitHub.)
2. من هذه المساحة: الملف موجود في `artifacts/apk/bin/` داخل مساحة العمل.
3. تحقّق من سلامة الملف قبل التثبيت:
   ```bash

   ```

> نسخة **debug** غير موقّعة بمفتاح إصدار وغير منشورة على متجر، لذلك سيظهر تحذير

> لا تستخدم هذه النسخة للتوزيع النهائي (ذلك في `MAG-13`).

## 2. التثبيت

### أ) بدون كابل (الأسهل)

1. انقل ملف الـAPK إلى الهاتف (USB، Google Drive، Telegram «ملف محفوظ»…).
2. افتح الملف من تطبيق «الملفات» ← قد يُطلب **السماح بالتثبيت من هذا المصدر** ← فعّله.
3. اضغط **تثبيت** ← **فتح**.

### ب) بجهاز الكمبيوتر (ADB)

```bash
adb devices                                  # يجب أن يظهر الجهاز كـ device
adb install -r debtmanagerpro-1.0.0-arm64-v8a_armeabi-v7a-debug.apk
adb shell monkey -p com.debtmanagerpro.debtmanagerpro -c android.intent.category.LAUNCHER 1
```

مراقبة سجل التطبيق أثناء الاختبار:

```bash
adb logcat -c
adb logcat python:D *:S          # أخطاء Python/Kivy فقط
adb logcat | grep -i -E "kivy|python|AndroidRuntime"
```

لإزالة التطبيق وبياناته بالكامل ثم البدء من جديد:

```bash
adb uninstall com.debtmanagerpro.debtmanagerpro
```

### ج) محاكي

* استخدم AVD بـ **Google APIs / API 34** (أو API 23 للتأكد من minSdk).
* فعّل **أذونات الجذر** إن أردت سحب قاعدة البيانات:
  `adb shell run-as com.debtmanagerpro.debtmanagerpro ls files`

> ملاحظة: المحاكي يعرض لوحة مفاتيح عربية إذا أضفت لغة عربية من
> Settings ← System ← Languages & input ← On-screen keyboard ← Languages.

## 3. قبل البدء

* مساحة حرة ≥ 150MB.
* نظام عربي (لغة الواجهة) إن أمكن، لتأكيد أن التطبيق يفرض اتجاهه بنفسه.
* أزل أي نسخة قديمة أولًا حتى تبدأ بقاعدة بيانات فارغة
  (`adb uninstall …` أو إعدادات Android ← التطبيقات ← مدير الديون ← مسح البيانات).

بيانات اختبار مقترحة (للتأكد من الأرقام والتقويم):

| المدين | الهاتف | الدين | ملاحظة |
| --- | --- | --- | --- |
| أحمد عبد الله | 07701234567 | 250000 IQD | قرض شخصي |
| مريم حسن | +9647709876543 | 120 USD | بيع بالتقسيط |

## 4. الشاشات السبع — خطوات ونقاط تحقق

### 1) المدينون (الشاشة الرئيسية)

* [ ] تظهر رسالة «لا يوجد مدينون مطابقون…» عند أول تشغيل.
* [ ] حقل البحث أعلى الشاشة، **محاذى لليمين**، ولا يتداخل مع أول بطاقة.
* [ ] زر `+` العائم ظاهر ولا يغطّي آخر بطاقة في القائمة.
* [ ] بعد إضافة مدينين: كل بطاقة تعرض الاسم، الهاتف كما أُدخل، الإجماليات، و«الديون: 1 | غير مسددة: 1».
* [ ] البحث باسم عربي يعمل، والبحث برقم هاتف يعمل، والبحث غير المطابق يُفرغ القائمة.

### 2) بيانات المدين (إضافة/تعديل)

* [ ] العنوان «بيانات المدين» وأيقونة الحفظ في الشريط العلوي.
* [ ] حقول: **الاسم الكامل**، **رقم الهاتف**، **ملاحظات**، وزر **حفظ** بعرض كامل.
* [ ] تحت حقلي الاسم والملاحظات تظهر معاينة «كما سيُحفظ» (اقرأها في اختبار الإدخال العربي أدناه).
* [ ] رقم الهاتف يُحفظ **كما أُدخل** (جرّب `+964770…` وتأكد أنه لا يُعاد تنسيقه).
* [ ] حفظ باسم فارغ يعطي رسالة خطأ مفهومة ولا يغلق الشاشة.
* [ ] الحفظ يعيدك للشاشة السابقة ويظهر المدين فورًا.

### 3) تفاصيل المدين

* [ ] بطاقة الملف: الاسم، الهاتف، تاريخ الإضافة، والملاحظات.
* [ ] قسم «الإجماليات حسب العملة»: إجمالي / المدفوع / المتبقي لكل عملة.
* [ ] عنوان «الديون (n)» وقائمة الديون، وبطاقة فارغة تشرح زر `+`.
* [ ] أيقونة القلم تفتح نفس النموذج بالبيانات معبّأة.
* [ ] أيقونة الحذف تطلب تأكيدًا يذكر أن الحذف يشمل الديون والدفعات والأقساط.
* [ ] زر `+` يفتح «بيانات الدين» لهذا المدين.

### 4) بيانات الدين

* [ ] حقول: المبلغ، زر العملة، تاريخ الدين (مضبوط على اليوم `YYYY-MM-DD`)، تاريخ الاستحقاق (اختياري)، الملاحظات، وزر **حفظ**.
* [ ] زر العملة بعرض كامل، ونصه «العملة: IQD»، والضغط عليه يفتح قائمة العملات.
* [ ] اختيار عملة أخرى يغيّر نص الزر ويُحفظ الدين بذلك الرمز.
* [ ] مبلغ غير رقمي أو تاريخ بصيغة خاطئة يعطي رسالة خطأ عربية واضحة.
* [ ] حفظ دين 250000 IQD ثم فتح «تفاصيل الدين» يعرض **250,000 IQD** بالتنسيق الصحيح.

### 5) تفاصيل الدين

* [ ] بطاقة الملخص: المبلغ الكلي في صف واحد مع شريحة الحالة (غير مسدد/مسدد…) دون تداخل.
* [ ] سطر «المدين: … - 07701234567» — الرقم يُعرض LTR داخل سطر عربي بلا انقلاب.
* [ ] عندما يكون الدين غير مسدد: زرّا **إضافة دفعة** و**تقسيم المتبقي إلى أقساط** ظاهران.
* [ ] «سجل الدفعات (n)» يبدأ برسالة «لا توجد دفعات مسجلة بعد».
* [ ] تعديل الدين يعمل، والحذف يطلب تأكيدًا.

### 6) إضافة دفعة

* [ ] السطر العلوي: «المتبقي على الدين: 250,000 IQD».
* [ ] المبلغ معبّأ مسبقًا بقيمة المتبقي، والتاريخ مضبوط على اليوم.
* [ ] رقم الإيصال اختياري؛ عند تركه فارغًا يُولَّد تلقائيًا بعد الحفظ.
* [ ] **منع الدفع الزائد**: أدخل مبلغًا أكبر من المتبقي ← رسالة خطأ، ولا تُسجَّل دفعة.
* [ ] دفعة جزئية 100,000 ← عند الرجوع يظهر «المدفوع 100,000» و«المتبقي 150,000» وسطر جديد في السجل.
* [ ] دفعة بكامل المتبقي تغيّر الحالة إلى مسدد وتُخفي أزرار الإضافة/التقسيم.

### 7) تقسيم الدين إلى أقساط

* [ ] السطر العلوي: «المتبقي القابل للتقسيم: …».
* [ ] القيم الافتراضية: 3 أقساط، أول استحقاق بعد شهر، الفاصل شهر واحد.
* [ ] **معاينة الأقساط** تنعرض فورًا وتتحدث مع كل تغيير، وكل سطر بالشكل: `1. 50,000 IQD - 2026-01-15`.
* [ ] تغيير العدد إلى 4 يضبط المعاينة ويوزّع الباقي بدقة (لا يضيع ولا يزيد أي مبلغ).
* [ ] الحفظ ينشئ الخطة، ويعود لتفاصيل الدين، وتظهر «خطة الأقساط: 0/4» في بطاقة المدين.
* [ ] محاولة إنشاء خطة ثانية لدين له خطة تعطي رسالة رفض.

## 5. فحص RTL والخط العربي

* [ ] كل الشاشات تبدأ من اليمين: العناوين، حقول الإدخال، والصفوف (التسمية يمينًا والقيمة يسارًا).
* [ ] لا تظهر **مربعات مفقودة** (`□□□`) في أي شاشة — الخط Amiri مضمّن في الـAPK.
* [ ] الحروف العربية متصلة وصحيحة الشكل (لا حروف مقطّعة ولا معكوسة).
* [ ] الأرقام والعملة تُعرض بالترتيب الصحيح: `250,000 IQD` لا `IQD 000,250`.
* [ ] الهاتف `+9647701234567` يظهر من اليسار لليمين دون انقلاب.
* [ ] التواريخ تظهر بصيغة مفهومة (`2026-01-15` أو الصيغة المعروضة) دون تشويه.
* [ ] النصوص الطويلة تُقصّ/تلتف بشكل مقبول ولا تخرج عن البطاقة.

## 6. إدخال النص العربي (قيد معروف ومقصود)

`TextInput` في Kivy/SDL2 **لا يعيد ترتيب النص العربي أثناء الكتابة** (لا bidi تفاعلي)،
لذلك:

* [ ] داخل حقل **الاسم**، اكتب `أحمد عبد الله`: قد يظهر أثناء الكتابة بترتيب بصري غير نهائي.
* [ ] **المعاينة أسفل الحقل** («كما سيُحفظ») يجب أن تعرض النص صحيحًا ومتصلًا ومرتبًا.
* [ ] بعد الحفظ، افتح المدين مرة أخرى: الاسم المعروض في البطاقات وفي التفاصيل **صحيح**.
* [ ] جرّب نصًا مختلطًا: `أحمد 2026` و`محمد - فرع بغداد` — الأرقام والشرطة في موضعها الصحيح.
* [ ] جرّب الملاحظات العربية الطويلة: «ملاحظة تجريبية لاختبار الالتفاف والاتجاه».
* [ ] الصق نصًا عربيًا من الحافظة يعمل، والحفظ يحتفظ به كاملًا.
* [ ] لوحة المفاتيح لا تغطي حقل الإدخال النشط (النافذة تنزلق للأعلى)، ويمكنك الوصول لزر الحفظ.
* [ ] جرّب حرف الهمزة والتشكيل (مثال: `مُحَمَّد`) وتأكد من عدم سقوط أي محرف.

**النتيجة المطلوبة:** القيمة المحفوظة منطقيًا هي ما كتبته بالضبط؛ اختلاف العرض داخل
حقل التحرير ليس خطأً في التطبيق، وأي انقلاب أو حروف مقطّعة في **المعاينة** أو **العرض**
يُسجّل كخطأ.

## 7. زر الرجوع والتنقل

* [ ] زر الرجوع في Android يعيدك خطوة واحدة (تفاصيل ← قائمة ← خروج)، لا يغلق التطبيق فجأة.
* [ ] عند الرجوع من نموذج لم تُحفظ فيه، يُتوقع فقدان التعديلات (سلوك مقصود) — سجّل إن أردت تأكيدًا.
* [ ] سهم/زر الرجوع في الشريط العلوي يعمل بنفس السلوك.

---

## 8. ثبات البيانات

* [ ] أغلق التطبيق كليًا (من قائمة التطبيقات الحديثة) وأعد فتحه: المدينون والديون والدفعات والأقساط موجودة.
* [ ] أعد تشغيل الهاتف وجرّب مرة أخرى.
* [ ] حذف مدين يحذف ديونه، ويظهر عند إعادة الفتح أنه غير موجود.
* [ ] لا يظهر أي حوار «التطبيق توقف عن العمل» خلال الجلسة.

## 9. تسجيل النتائج

اجمع لكل شاشة: صورة شاشة + نتيجة (نجح/فشل) + وصف قصير + مقتطف `logcat`.

```
الصور:   اختبار/<الرقم>_<اسم الشاشة>.png
السجل:   adb logcat -d > logcat.txt
```

عند وجود فشل، أرفق في المهمة:

1. اسم الشاشة والخطوة.
2. ما توقّعته وما ظهر.
3. لقطة الشاشة، وأسطر `logcat` ذات الصلة.

## 10. قيود معروفة مسبقًا (ليست أخطاء)

| القيد | التفصيل |
| --- | --- |
| bidi داخل حقل الكتابة | لا يعيد Kivy/SDL2 ترتيب العربية أثناء الكتابة؛ المعاينة أسفل الحقل هي المرجع، والقيمة المحفوظة صحيحة. |
| تحذير Play Protect | الـAPK موقّع بمفتاح debug وغير منشور على متجر. |
| حجم الـAPK | 48MB لأنه يضم معماريتَي 64-bit و32-bit. |
| العملات | لا تحويل بين العملات؛ الإجماليات تُعرض لكل عملة على حدة. |
| الرسائل/الإشعارات | المرحلة 3 (`MAG-5`, `MAG-12`) لم تُنفَّذ بعد؛ إذن الإشعارات مُعلن فقط. |
