# ملاحظات Android والصلاحيات

## البناء

```bash
buildozer -v android debug
```

* `android.minapi = 23` (Android 6.0) هو الحد الأدنى المطلوب للمشروع.
* `android.api = 34` و `android.archs = arm64-v8a, armeabi-v7a`.
* قاعدة البيانات تُحفظ داخل مساحة التطبيق الخاصة (`App.user_data_dir`)،
  أي `/data/user/0/com.debtmanagerpro/files/debt_manager.db`، ولا تحتاج أي
  صلاحية تخزين.
* `buildozer.spec` لا يضمّن مجلد `tests/` أو `.venv` داخل الحزمة.

## الصلاحيات الحالية (المرحلة 1 و2)

| الصلاحية | لماذا |
|---|---|
| `INTERNET` | غير مستخدمة الآن، مُعلنة للاتصال المستقبلي بالخادم المحلي/الإضافات |
| `POST_NOTIFICATIONS` | لا تُطلب وقت التشغيل الآن؛ ستُستخدم في تذكيرات المرحلة 3 |

لا يوجد في هذا الإصدار إرسال رسائل SMS، ولا اتصال هاتفي، ولا قراءة جهات
الاتصال. لذلك لا تُعلَن صلاحياتها مطلقًا بعد.

## قيود الإصدارات والبدائل الرسمية

هذه ملاحظات إلزامية للمراحل القادمة؛ لن تُستخدم أي حلول غير رسمية لتجاوزها.

### 1) الرسائل النصية SMS (المرحلة 3)
* `SEND_SMS` صلاحية خطيرة تُطلب وقت التشغيل منذ Android 6 (API 23).
* قراءة صندوق الرسائل (`READ_SMS`) مقيّدة، وتتطلب عادةً أن يكون التطبيق هو
  تطبيق الرسائل الافتراضي، وسياسات Google Play تمنع استخدامها لغرض غير ذلك.
* البديل الرسمي الموصى به: فتح تطبيق الرسائل الافتراضي عبر Intent
  (`Intent.ACTION_SENDTO` مع `smsto:`) أو رابط واتساب، وإرسال الرسالة بيد
  المستخدم؛ أو أن يصبح التطبيق تطبيق SMS افتراضياً ويطبّق واجهة الدور كاملة.
  لا استخدام لـ "Accessibility" أو أي تجاوز غير رسمي.

### 2) المكالمات
* `CALL_PHONE` تحتاج طلبًا وقت التشغيل؛ البديل الآمن هو `Intent.ACTION_DIAL`
  الذي يفتح لوحة الاتصال دون صلاحية.
* سجل المكالمات (`READ_CALL_LOG`) محجوز لتطبيقات الاتصال الافتراضية.

### 3) التخزين والتصدير
* Android 10+ (API 29) يفرض التخزين المقيّد (Scoped Storage).
* لا حاجة لصلاحية تخزين لملفات التطبيق الخاصة.
* لتصدير تقارير: استخدم Storage Access Framework
  (`ACTION_CREATE_DOCUMENT`) أو `MediaStore` بدل مسارات `/sdcard` المباشرة.
* على Android 9 وأقدم فقط يلزم `WRITE_EXTERNAL_STORAGE` مع
  `android:maxSdkVersion="28"` إن احتجنا الكتابة إلى التخزين المشترك.

### 4) الإشعارات والتذكيرات
* Android 8+ (API 26) يتطلب قنوات إشعارات (Notification Channels).
* Android 13+ (API 33) يتطلب طلب `POST_NOTIFICATIONS` وقت التشغيل.
* Android 12+ (API 31) يقيّد المنبّهات الدقيقة
  (`SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM`)؛ الأفضل استخدام
  `AlarmManager.setAndAllowWhileIdle` غير الدقيق أو `WorkManager` للتذكيرات
  اليومية بدل طلب صلاحية منبّه دقيق.
* Android 14+ (API 34) يتطلب تحديد نوع خدمة المقدمة (Foreground Service Type)
  عند تشغيل خدمة مستمرة، مع إعلانها في المانيفست.

### 5) العمل في الخلفية
* Doze و App Standby تقيّدان المؤقتات؛ المهام الدورية يجب أن تكون عبر
  `WorkManager` (أو `JobScheduler`)، وليس خدمة خلفية دائمة.

### 6) رؤية الحزم (Android 11+)
* عند الاستعلام عن تطبيقات أخرى (واتساب مثلاً) يلزم قسم `<queries>` في
  المانيفست؛ لا يمكن الاعتماد على `QUERY_ALL_PACKAGES` لحل مشكلة عامة.

## مسار الترقية

1. إضافة `android.permissions` للمرحلة 3 فقط عند تنفيذ كل ميزة.
2. طلب الصلاحيات وقت التشغيل من داخل الواجهة مع شرح للمستخدم.
3. اختبار على أجهزة/محاكيات API 23 و29 و33 و34 قبل الإصدار.
